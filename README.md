# 太吾捏脸经典版

《太吾绘卷》经典版人物外貌系统的粉丝复刻工具，非官方作品。

- 选择五官、发型、特征、胡须和衣着，调整配色与颜色联动。
- 设置性别、异相和年龄，随机生成外貌。
- 导出透明背景 PNG，支持 JSON 外貌配置导入与导出。
- 外貌自动保存在当前浏览器，适配桌面与移动设备。
